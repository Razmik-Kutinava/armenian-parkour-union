## Решения (агент)

1. **Гонки** (`race.test.ts`, коммит в тестовую базу как у регистраций): (а) два старта одного участника разом — одна попытка, второй `running`; внеочередная списывается один раз; (б) двойная отправка разом — одна запись результата, оба ответа одинаковые, одно письмо; (в) отправка и ленивое закрытие просроченной (`settleExpired`) разом — одно письмо; (г) один экзамен: два проверяющих принимают два последних видео разом, и сданный тест вместе с последним видео — один `exam`, одна запись `exam.course_complete`, одна пара писем; (д) два проверяющих принимают одну отправку разом — одно решение, второй `bad_state`.
2. **Уборка гонок** (`race-support.ts` портала): поверх `raceDb` из `registrations/race-support.ts` (сессии, `race`, участники и сотрудники); свои строки (курс, темы, вопросы, задания, заявки, попытки, отправки, экзамены) удаляются по `id` в порядке ссылок; журнал остаётся (append-only), письма — в фейковый ящик. `registrations/race-support.ts` не меняется.
3. **Ответы не уходят** (`quiz-secrets.test.ts`): в JSON всего, что отдаётся странице, нет `correct_index` / `correctIndex` / `question_id` — `quizPage` во всех состояниях (до попытки, после несданной, после сданной с историей, просроченной, предпросмотр админа), `quizStatus` (блок на портале), результат `submitAttempt` (только счёт), прогресс `/cabinet/training`. Вопросы — только `{ text, options }`.
4. **Подмена `id`** (`swap.test.ts`): своя попытка курса A под slug курса B — `not_found` для сохранения и отправки, строка не меняется; чужая попытка — ответы и `submitted_at` не меняются (не только `not_found`); страница практики не показывает чужие отправки того же задания; карточка проверки — чужой / несуществующий `id` → нет данных.
5. **Права** (`rights.test.ts`): одна таблица — каждое действие `training.*` (курс, тема, урок, PDF, вопрос, импорт, задание, решение по заявке, внеочередная попытка, решение по видео) × роли member / editor / moderator / admin; `not_allowed` ровно у ролей вне `04`, ничего не записано. Предпросмотр портала — только `training.manage`.
6. **RED**: тесты на работающий код — часть может быть зелёной сразу (это фиксация требований, не ошибка); в RED-коммит — все, в отчёте — какие упали. Упавшие — фикс в GREEN по слоям (`quiz-start.ts`, `quiz-submit.ts`, `quiz-close.ts`, `course-complete.ts`, `practice-review.ts`), без смены порядка блокировок.
