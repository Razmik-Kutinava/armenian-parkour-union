## Задача

1.5 Авторизация: регистрация (с данными родителя до 18 лет), вход, выход, подтверждение email, сброс пароля, ограничение попыток (`09`; `03` разд. 1, 13; `04` разд. 6; `06` разд. 4.11, 6).

Решения владельца 2026-10-07: только email + пароль (Google — отдельным шагом, когда будут ключи); письма — ссылкой в лог сервера, пока нет почты; пароль 8–128 символов без требований к составу; лимиты попыток — константы в коде.

Устройство: HTTP-обработчик Better Auth (`/api/auth/*`) **не** подключаем — иначе через него можно зарегистрироваться в обход проверок (родитель, согласие). Всё идёт через form actions → Zod → `auth.api.*`. Встроенный `rateLimit` Better Auth на прямые вызовы `auth.api` не действует, поэтому лимит — свой модуль на таблице `rate_limit`.

## Файлы (ожидаемо)

- `src/lib/validation/auth.ts` (+ `auth.test.ts`) — Zod: регистрация (родитель обязателен до 18), вход, запрос сброса, новый пароль
- `src/lib/server/auth/index.ts` — экземпляр Better Auth (drizzle, uuid, `image` → `avatarKey`, письма, блокировка входа)

- `src/lib/server/auth/return-to.ts` (+ тест) — адрес возврата только внутренний
- `src/lib/server/mail/index.ts` — отправка писем (сейчас — в лог)
- `src/routes/[[lang=lang]]/(site)/(auth)/{login,register,forgot-password,reset-password,verify-email,logout}/`
- `src/lib/i18n/messages/{en,ru}.ts` — тексты форм; `tests/e2e/auth.spec.ts`

## Не ломать

- Совершеннолетний регистрируется без данных родителя; несовершеннолетний без них — нет (ошибка у полей, введённое сохраняется).
- Заблокированный (`status = blocked`) или удалённый (`deleted_at`) не входит даже с верным паролем.
- После `/login?returnTo=//evil.com` переход только на внутренний путь.
- i18n и редирект `/en` из 1.3 работают; `/dev/design` в проде — 404.
