# 05-ADMIN-PANEL: Админ-панель

> Отвечает на вопросы: какие разделы в админке, какие поля в формах, какие списки, фильтры и действия.
> Правила работы агента — `.cursor/rules/main.mdc`. Структура данных — только `02-DATABASE.md`. Логика — только `03-BUSINESS-RULES.md`. Права — только `04-ROLES-PERMISSIONS.md`.

Админ работает без кода и без разработчика.
Админка живёт в `src/routes/admin/`. Доступ и права проверяются на сервере в каждом разделе и каждом action (см. `04`, раздел 5).

**Для агента:**
- Делать только разделы текущего этапа `09-ROADMAP.md`, не всю админку сразу.
- Поле формы, которого нет в `02-DATABASE.md`, — стоп и вопрос (см. раздел 26), схему самому не расширять.
- Логику (баллы, степени, платежи) админка не реализует сама — только вызывает сервисы из `src/lib/server/services/`.
- Функции, требующие новой библиотеки (перетаскивание, очистка HTML, PDF), — сначала согласование.

## 1. Общие принципы интерфейса

1. **Единый шаблон раздела:** список → создание → карточка и редактирование. Все разделы выглядят и работают одинаково.
2. **Списки:** таблица с пагинацией (25 на страницу), поиск, фильтры, сортировка по ключевым колонкам. Фильтры сохраняются в URL (ссылкой можно поделиться).
3. **Формы:** валидация на сервере (Zod), ошибки показываются у поля. Незаполненные обязательные поля помечены. Несохранённые изменения предупреждают при уходе со страницы.
4. **Многоязычные поля:** вкладки EN / HY / RU. Английский обязателен, остальные необязательны (при пустом показывается английский).
5. **Статусы контента:** `draft` → `published` → `archived`. Любой контент можно подготовить заранее и опубликовать позже (поле даты публикации).
6. **Предпросмотр:** для событий, новостей, страниц, hero-блоков и товаров кнопка «Предпросмотр» показывает страницу так, как увидит посетитель, до публикации.
7. **Опасные действия** (отмена события, возврат, отзыв сертификата, ручные баллы, блокировка, смена роли) требуют подтверждения в диалоге, а где указано, ещё и комментарий. Все пишутся в `audit_log`.
8. **Удаление мягкое.** Кнопки «Удалить» нет там, где на запись есть ссылки: вместо неё «Архивировать» или «Скрыть».
9. **Загрузка файлов:** выбор из медиабиблиотеки или загрузка новой (перетаскиванием). Проверка типа и размера. У изображений поле `alt`.
10. **Пустые состояния:** если в списке ничего нет, показывается подсказка и кнопка «Создать».
11. **Уведомление о результате:** после каждого действия сообщение об успехе или понятная ошибка.
12. **Адаптивность:** админка должна нормально работать на телефоне (модерация и отметка посещаемости делаются в день события с телефона).
13. **Меню показывает только доступные роли разделы** (это удобство, не защита).

Общие элементы (таблица, фильтры, форма с вкладками языков, диалог подтверждения) делаются один раз как компоненты в `src/lib/components/` и переиспользуются во всех разделах.

## 3. Дашборд

Показывает то, что требует внимания, а не красивую статистику.

| Блок | Видят | Содержимое |
|---|---|---|
| Требует действия | moderator, admin | счётчики с ссылками: видео на проверке, согласия на проверке, новые заказы, платежи с ошибкой, регистрации в очереди ожидания |
| Ближайшие события | все | 3 ближайших события: дата, регистрации и лимит |
| Главная сейчас | editor, admin | какие hero-блоки активны, ссылка на раздел |
| Последние регистрации | admin | 10 последних новых пользователей |
| Подозрительные баллы | admin | крупные и частые начисления за последние 7 дней |
| Короткая статистика | admin | участников всего, активных членств, платежей за месяц (взносы, донаты отдельно) |

Каждый счётчик показывается только тем, у кого есть право на соответствующий раздел (`04`, раздел 5.1).

## 4. Главная (hero-блоки)

**Список:** карточки с превью, порядок меняется перетаскиванием.
Колонки/поля карточки: превью, заголовок, тип, активен (переключатель), период показа, порядок.
Фильтры: тип, активные / неактивные.
Сверху: блок «Что сейчас на главной» с живым предпросмотром.

**Форма:**
| Поле | Тип | Обязательно | Примечание |
|---|---|---|---|
| Тип | выбор: событие, презентация, видео, персона, свой блок | да | определяет остальные поля |
| Заголовок | текст ×3 языка | да | |
| Подзаголовок | текст ×3 языка | нет | |
| Фон / изображение | медиа | зависит от типа | |
| Событие | выбор из опубликованных | да для «событие» | подтягивает данные события |
| Персона | поиск по участникам | да для «персона» | только если разрешён показ (`03`, раздел 11) |
| Ссылка на видео | URL | да для «видео» | YouTube / Instagram |
| Текст кнопки | текст ×3 языка | нет | |
| Ссылка кнопки | URL или страница сайта | нет | |
| Период показа | с даты, по дату | нет | |
| Активен | переключатель | — | |

**Действия:** создать, редактировать, включить / выключить, перетащить порядок, дублировать, предпросмотр, архивировать.
**Правила:** лимит активных блоков из `03`, раздел 11. При превышении сообщение «Выключите другой блок». Блок события с неопубликованным событием помечается предупреждением.

## 5. События

**Список:**
Колонки: обложка, название, даты, место, статус, регистраций / лимит, цена.
Фильтры: статус, период (предстоящие, прошедшие), город, платные / бесплатные.
Поиск: по названию.

**Форма события:**
| Поле | Тип | Обязательно |
|---|---|---|
| Название | текст ×3 языка | да (EN) |
| Адрес страницы (slug) | текст, генерируется из названия, можно править | да |
| Описание | редактор (TipTap) ×3 языка | нет |
| Обложка | медиа | нет |
| Дата и время начала, окончания | дата-время | да |
| Название места | текст | нет |
| Адрес, город | текст | нет |
| Координаты (для карты) | число, число | нет |
| Лимит участников | число или «без лимита» | нет |
| Цена и валюта | число, выбор (`0` бесплатно) | да |
| Открытие и закрытие регистрации | дата-время | нет |
| Статус | черновик / опубликовано | — |
| Дата публикации | дата-время | нет |

**Вкладка «Категории»:** список категорий внутри события (название ×3 языка, дисциплина, возраст от/до, лимит, порядок). Добавить, изменить, удалить (только без регистраций).

**Вкладка «Регистрации»** (видят moderator, admin; редактор видит только число):
Колонки: участник, категория, статус, оплата, дата регистрации, отметка «пришёл», место, оценка.
Фильтры: статус, категория, оплачено / нет.
Действия: перевести из очереди ожидания, отменить регистрацию, добавить участника вручную, экспорт CSV.

**Режим «День события»** (для телефона): крупный список участников с поиском, одним нажатием «пришёл» / «не пришёл». Отметка запускает начисление баллов (`03`, раздел 7).

**Вкладка «Результаты»:** по каждому участнику место и оценка, быстрый ввод таблицей. Сохранение с `place = 1` запускает баллы за победу. Кнопка «Завершить событие» переводит его в `finished`.

**Действия:** создать, сохранить черновик, предпросмотр, опубликовать / снять, дублировать (для повторяющихся событий), отменить событие (admin, с причиной и рассылкой участникам), архивировать.
**Правила:** событие с регистрациями удалить нельзя, только отменить. Изменение даты или места опубликованного события предлагает отправить участникам уведомление.

## 6. Пользователи

**Список:**
Колонки: имя, email, степень, роль, членство (до какой даты), баллы, статус, дата регистрации.
Фильтры: степень, роль, статус, членство (активно, истекло, нет), возрастная группа (до 18, от 18), город, есть профиль тренера или судьи.
Поиск: по имени, email, телефону.
Для модератора скрыты email и телефон (`04`, раздел 4) — поля не отдаются с сервера, поиск по ним модератору недоступен.

**Карточка пользователя** (вкладки):
| Вкладка | Содержимое |
|---|---|
| Профиль | поля профиля, данные родителя, роль, статус |
| Членство и платежи | история членств и платежей |
| События | регистрации и результаты |
| Экзамены и сертификаты | история, кнопки «назначить экзамен», «выдать сертификат» |
| Баллы | баланс, журнал, кнопка «Корректировка» |
| Видео | список видео участника и статусы |
| Заказы | заказы в магазине |
| Согласия | документы и статусы |
| История действий | записи `audit_log` по этому пользователю |

Вкладки и кнопки показываются по правам роли (`04`, разделы 3.2 и 4); например, модератору не видны платежи и кнопка «Корректировка».

**Действия (admin):**
- редактировать профиль;
- сменить степень вручную (комментарий обязателен);
- сменить роль (нельзя себе, `04`, раздел 6);
- заблокировать / разблокировать (с причиной, сессии отзываются);
- сбросить пароль (отправить письмо);
- подтвердить email вручную;
- создать пользователя вручную (для переноса старой базы), с отправкой письма «задайте пароль».

**Правила:** защита последнего админа, запрет блокировать себя (`04`, раздел 6).

## 7. Экзамены

**Список:** Колонки: участник, тип, дата, экзаменатор, результат, оценка.
Фильтры: тип, результат, период.
**Форма:** участник (поиск), тип экзамена, дата и время, привязка к событию (необязательно), экзаменатор (выбор из moderator и admin), заметки.
**Результат:** результат (сдал / не сдал / отменён), оценка, комментарий. После «сдал» появляется кнопка «Выдать сертификат» (только admin).
**Правила:** проверка условий допуска (`03`, раздел 3). Нельзя назначить экзамен без действующего членства. Предупреждение, если степень не подходит.

---

## 8. Сертификаты

**Список:** Колонки: номер, участник, тип, уровень или категория, дата выдачи, срок, статус.
Фильтры: тип, статус, истекающие в течение 60 дней.
**Выдача (admin):**
| Поле | Примечание |
|---|---|
| Участник | поиск |
| Тип | степень / тренер / судья |
| Уровень или категория | для степени: продвинутый или профи |
| Экзамен | выбор сданного экзамена (можно пусто с комментарием, `03`, раздел 4) |
| Дата выдачи, срок действия | по умолчанию из настроек |
| Комментарий | обязателен при выдаче без экзамена |

После сохранения: обновляются степень и баллы (одной транзакцией), затем генерируется PDF и уходит письмо участнику.
**Действия:** просмотреть и скачать PDF, пересоздать PDF, отозвать (admin, причина обязательна), скопировать ссылку проверки.
**Правила:** редактировать номер нельзя.

---

## 9. Тренеры и судьи

**Список:** Колонки: участник, вид (тренер / судья), категория, номер лицензии, сертификат, публичный, активен.
Фильтры: вид, активные, публичные.
**Форма (admin):** участник, вид, категория, номер лицензии, описание ×3 языка, фото, «показывать публично», «активен».
**Правила:** профиль создаётся автоматически при выдаче сертификата и деактивируется при истечении (`03`, раздел 5). Здесь его можно скорректировать.

## 10. Согласия

**Список:** Колонки: участник, тип (родитель / мед. допуск / приватность), статус, дата подписания, действует до.
Фильтры: тип, статус, истекают в течение 30 дней.
**Карточка:** данные участника и родителя, просмотр файла (скан или фото), кнопки «Одобрить» / «Отклонить» (с причиной), поле «Действует до».
**Правила:** участнику уходит письмо с решением. Файлы согласий — личные данные: доступ к файлу только по временной подписанной ссылке, не публичным URL.

---

## 11. Видео (модерация)

**Список (очередь):** по умолчанию статус «на проверке», старые сверху.
Колонки: участник, превью или ссылка, платформа, событие, дата добавления, статус.
Фильтры: статус, платформа.
**Просмотр:** встроенный проигрыватель или кнопка «Открыть ссылку».
**Действия:** одобрить (начисляются баллы), отклонить (причина обязательна), скрыть. Быстрые кнопки прямо в списке и пакетная обработка выбранных.
**Правила:** лимиты и дубли по `03`, раздел 8.

---

## 12. Журнал баллов

**Список:** Колонки: дата, участник, сумма (+/−), причина, источник, комментарий, кто выполнил.
Фильтры: участник, причина, период, ручные операции, сумма больше N, подозрительное.
**Действия (admin):**
- «Ручная корректировка»: участник, сумма (+ или −), комментарий (обязателен). Показывает баланс до и после.
- «Отменить запись»: открывает форму `reversal` с подтверждением и комментарием. Недоступно для уже отменённых.
- Экспорт CSV.

Модератор видит журнал только для чтения.
**Правила:** редактировать и удалять записи нельзя (`03`, раздел 6.3). Баланс не может уйти ниже нуля.

---

## 13. Правила баллов

**Список правил:** код, название, баллы, активно, кем и когда изменено.
**Редактирование (admin):** название ×3 языка, количество баллов, активно. Код не меняется.
**Правила:** изменение действует только на будущие начисления. Каждое изменение пишется в `audit_log`. Создавать новые коды из админки нельзя (они привязаны к коду сервисов).

---

## 14. Товары (магазин)

**Список:** Колонки: фото, название, цена в баллах, остаток, статус.
Фильтры: статус, нет в наличии.
**Форма:** название ×3 языка, описание (редактор) ×3 языка, фото (несколько, порядок перетаскиванием), цена в баллах, варианты (размер, цвет: список значений), остаток или «без ограничения», статус, порядок показа.
**Действия:** создать, опубликовать / скрыть, дублировать, архивировать.
**Правила:** смена цены на старые заказы не влияет.

---

## 15. Заказы

**Список:** Колонки: номер, участник, состав, сумма в баллах, статус, дата.
Фильтры: статус, период.
**Карточка:** состав заказа с вариантами, данные доставки, комментарий участника.
**Действия:** сменить статус (новый → подтверждён → отправлен → доставлен), добавить заметку об отправке (трек-номер), отменить заказ (admin, возврат баллов и остатка).
**Правила:** смена статуса отправляет участнику письмо. Модератор не может выбрать статус «отменён» — отмена только у admin (`04`, раздел 3.2).

---

## 16. Платежи (admin)

**Список:** Колонки: дата, плательщик, тип (взнос / донат / участие), сумма, валюта, статус, провайдер.
Фильтры: тип, статус, период, провайдер, «требуют проверки» (ошибки и расхождения).
**Карточка:** все данные платежа, связанные записи (членство, регистрация), ответ провайдера (для разбора спорных случаев).
**Действия:**
- подтвердить вручную (для переводов вне сайта): плательщик, тип, сумма, дата, комментарий; ставится `provider = manual`;
- оформить возврат (причина обязательна);
- отправить квитанцию повторно;
- выгрузить CSV (взносы и донаты отдельными выгрузками по периоду).

**Правила:** платёж `paid` нельзя удалить и изменить сумму. Детали сценариев — `07-PAYMENTS.md`.

---

## 17. Назначения донатов

**Список:** название, активно, порядок. **Форма:** название ×3 языка, активно. Сумма собранного по назначению показывается в списке (только для admin).

---

## 18. Новости и блог

**Список:** Колонки: обложка, заголовок, статус, дата публикации, автор.
Фильтры: статус, тег, период. Поиск по заголовку.
**Форма:** заголовок ×3 языка, адрес (slug), краткое описание ×3 языка, текст (редактор) ×3 языка, обложка, теги, статус, дата публикации (отложенная публикация), автор.
**Редактор текста:** заголовки, жирный, курсив, списки, ссылки, изображения (из медиатеки), встроенное видео (YouTube/Instagram), цитаты. HTML очищается от опасного кода при сохранении.
**Действия:** сохранить черновик, предпросмотр, опубликовать, снять, архивировать, дублировать.

---

## 19. Страницы

**Список:** название, адрес, статус, когда изменена.
**Форма:** заголовок ×3 языка, текст (редактор) ×3 языка, статус.
**Правила:** адреса системных страниц («О федерации», «Правила», «Контакты», «Политика конфиденциальности») создаются seed-скриптом и не удаляются, только редактируются.

---

## 20. Медиабиблиотека

**Список:** сетка миниатюр, поиск по имени, фильтр по типу.
**Действия:** загрузить (несколько файлов сразу), указать alt-текст, скопировать ссылку, удалить.
**Правила:** файл, используемый на странице, событии, товаре или в hero-блоке, удалить нельзя (показывается, где он используется). Допустимые типы и размеры задаются в коде и документируются в `01-STACK.md`.

## 23. Админы и роли (admin)

**Действия:** выдать роль (поиск участника → выбор роли → подтверждение), забрать роль (возврат к `member`).
**Правила:** защита последнего админа и запрет менять роль себе (`04`, раздел 6). Для admin рекомендуется двухфакторная защита после MVP.
