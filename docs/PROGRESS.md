## Известные проблемы и долги
- CSP (`csp.config.ts`): новый внешний хост — сначала туда; медиа — `https://media.parkour.am`. Отчёты CSP — не сделаны.
- e2e: `global-setup` чистит `e2e-*@example.com`; два прогона против одной базы — нет; `hydrated` перед вводом; локально медленнее CI (Neon); `registrations/race` «cancel and join» локально таймаут 20 с — в CI зелёный; полный Vitest локально под параллелью — таймауты Neon (зона отдельно зелёная).
- Роли Neon: прод `parkour_app`, dev `parkour_dev_app`, бэкап `backup_reader`. `npm audit`: moderate в drizzle-kit / vitest (dev).
- UptimeRobot раз в 60 мин — интервал не уменьшать (Neon CU). `cron.yml` на часы.
- Браузерный Sentry (~34 КБ): лениво не грузим (REVIEW этапа 8).
- Пароль бэкапов — у владельца; в GitHub — `PROD_DATABASE_URL`, `BACKUP_PASSPHRASE` (обновить `01` по просьбе).
