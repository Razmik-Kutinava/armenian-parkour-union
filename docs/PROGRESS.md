## Известные проблемы и долги
Здесь — только общее для всех задач. Известное одной зоны (ниже порога REVIEW этапов 5–7, VPOS 3.13, задачи этапов 1–2) — пункт «Известное» в её разделе `zone-notes.md`.
- CSP (`csp.config.ts`, собирается при сборке): новый внешний хост (картинки, iframe, `fetch` из браузера, аналитика) — сначала туда, иначе браузер молча заблокирует; хост медиа зашит `https://media.parkour.am` — при смене `R2_PUBLIC_URL` поправить. Новый хост оплаты или входа (форма с редиректом наружу) — в `form-action`. Отчёты о нарушениях CSP — не сделаны.
- e2e (после `3c46b79`): перед прогоном `global-setup.ts` мягко удаляет **всех** `e2e-*@example.com` и архивирует блоки hero `E2e …` — два прогона против одной базы одновременно не поддерживаются (на одной машине их и так не даёт порт 4173; параллельный чат в этом репозитории — ждать его прогон, не останавливать чужой `vite preview`). Новый тест с вводом сразу после `goto` / `reload` — сначала `hydrated(page)`; заголовки создаваемых записей — уникальные (остатки прерванного прогона видны в списках). Локально e2e медленнее CI в разы (Neon ~70 мс на запрос): один полный прогон — 3–5 мин; посторонний `vite dev` на машине их ещё замедляет. Лимит входа — на IP, все e2e с одного адреса: `auth` «sixth login attempt» повторяет серию, если чужой вход вмешался, `cabinet` «password change» повторяет вход до 75 с. `audit-coverage` один раз упал в полном Vitest, повтор и отдельный прогон зелёные.
- Роли Neon (2026-10-25): прод — `parkour_app` (только `parkour_prod`, пароль только в Fly), dev — `parkour_dev_app` (только `parkour_dev`, `.env`), бэкап — `backup_reader`; `neondb_owner` в коде не используется. Версии из `sv create`: SvelteKit 3, Vite 8, TypeScript 6, Tailwind 4, ESLint 10 — актуальные на дату установки. Драйвер `postgres` (postgres.js) добавлен как часть Drizzle; в таблице стека `01` отдельной строкой не указан. `npm audit`: 4 moderate в esbuild внутри drizzle-kit (только dev, на сайт не попадает; CI проверяет prod-зависимости уровня high). Следить за обновлением drizzle-kit.
