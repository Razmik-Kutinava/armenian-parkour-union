# /patch — кривая задача после REVIEW

Когда: после REVIEW или проверки владельцем поведение кривое, дыра в требованиях или надо вернуть убранное. Не для мелочей и не для новой задачи по роадмапу.

## Сделай
1. Описать, что не так: ожидалось / получилось / где (`файл:строка`, документ и раздел).
2. Решить тип: **патч** (правка в рамках той же задачи) или **доп. задача** (новая строка в `09-ROADMAP.md` — только с согласия владельца).
3. Требования расходятся с документами — стоп и вопрос, в `PROGRESS.md` («Открытые вопросы»).
4. Записать в `docs/todo.md` как новую задачу (секции SPEC). Коммит.
