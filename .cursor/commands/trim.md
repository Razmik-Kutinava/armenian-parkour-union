# /trim — порезать документы состояния (экономия контекста)

Только перенос и сжатие текста. Ничего не удалять насовсем, смысл не менять, код не трогать. Без SBR.

## Когда

Вручную — `/trim`. Сам агент — если сработал любой триггер:

| Триггер | Где проверяется |
|---|---|
| `PROGRESS.md` > 80 строк | `/start`, `/review` шаг 4, «Порядок шага» шаг 4 |
| «Сделано» > 5 записей | там же |
| В «В работе» или «Открытые вопросы» есть закрытые пункты | там же |
| «Последний `/trim`» в «Статусе» старше 7 дней | `/start` |
| Этап закрыт | обязательно, перед переходом на следующий этап |

В `/start` агент ничего не правит — только пишет `Next: /trim`. В `/review` и в обычном шаге — делает `/trim` сам, в том же коммите или следующим `docs:`-коммитом.

## Куда что переносится

| Из `PROGRESS.md` | Куда |
|---|---|
| Старые записи «Сделано» (оставить последние 5, одной строкой с хешем) | `docs/archive/done-stage-N.md`, полная запись, дописать в конец |
| Закрытые пункты «В работе» | туда же, как запись «Сделано» |
| Новые вопросы и смена статусов | `docs/questions.md` — источник правды |
| Вопросы не текущего и не следующего этапа | только в `docs/questions.md` |
| Новые решения владельца | `docs/decisions.md`, дописать строку |
| Этап закрыт: решённые строки его вопросов | из `questions.md` в `archive/done-stage-N.md` |

`N` — этап, к которому относится запись. Архив только дописывается.

## Шаги

1. Посчитать до: строки `PROGRESS.md`, записи «Сделано», строки вопросов в `questions.md`.
2. Перенести по таблице выше.
3. В `PROGRESS.md` переписать «Сводку» (3–5 строк: где мы, что осталось, что блокирует), «Этапы», «Последний `/trim`» = сегодня.
4. Таблица «Открытые вопросы» в `PROGRESS.md` — только открытые строки текущего и следующего этапа из `questions.md`.
5. Документ `00`–`09` менялся по просьбе и его разделы сдвинулись — обновить его «Оглавление» (только названия разделов).
6. Проверка: ни одна запись не потерялась (записи «Сделано» до = в архиве + в `PROGRESS.md`; вопросы до = после), `PROGRESS.md` ≤ 80 строк.
7. Коммит `docs: trim PROGRESS (…)`.

## Отчёт

`PROGRESS: было N строк → стало M` · перенесено: Сделано K, вопросы Q, решения D · `Коммит: <хеш>`

## Обязательно в конце

Вручную: `Next: /start`
Из `/review` или обычного шага: вернуться к нему (`Next: продолжить …`)
